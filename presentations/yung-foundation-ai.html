01The deck · September 2026

Drafts, not decisions

The Yung Foundation’s admin is bilingual: every title, summary and caption is written twice, Marathi first. In September 2026 it gained AI help — translation both ways, writing help, photo descriptions, gallery and news suggestions from the photo library — plus a real body editor, WhatsApp sharing, map links and a live preview. One rule sits under all of it: the AI drafts, an editor decides.

02The problem

Every field, twice

The site speaks Marathi first, to readers in the Satpuda hills around Dhadgaon and Shirpur, and English second. Almost every text field in the admin is a मराठी / English pair, and a small team fills them in after field work, often from a phone.

What piled up: English halves left empty, photos with no alt text (a screen reader gets nothing), newspaper cuttings on someone’s phone waiting to become news items, and a body editor that could not put a photo between two paragraphs.

03The rule

The AI drafts. An editor decides.

A foundation’s site makes claims about real people and real numbers, and donors rely on them. So no AI result reaches the public site on its own. Five rules, each enforced in code rather than left to good behaviour:

1

It lands unsaved

Every result goes into the form, not the database, with one level of Undo. A reload throws it away.

2

Bulk means a review list

Fifty photo descriptions or twelve clippings come back as a list with ticks. Nothing is written until it is ticked and saved.

3

It creates drafts only

Suggested categories, albums, gallery photos and news items are created unpublished.

4

It must not invent

The prompt forbids new facts, figures, names, dates, places and quotes. Code checks the ones a model writes anyway.

5

Some words stay human

Quotes and figures are translate-only. Public inbox messages never reach a provider.

AI drafts→ unsaved, in the form→ editor reads and fixes→ Save→ still hidden until published

05WritingAI

Translation, both directions

Under every bilingual field: Draft English once the Marathi half has text, Draft Marathi once the English half does. Rich bodies translate as HTML and keep their photos where they were.

Where it gets used

  • A programme written up in Marathi after a camp: the English half in one click, then corrected.
  • A board member’s English note for the About page: a Marathi draft to fix, not a blank box to fill.
  • Alt text and captions in the photo library: the same two buttons.

One Undo puts back the value from before the last AI change. Nothing is saved until the editor presses Save.

06WritingAI

Write, expand, shorten, and every number checked

“AI writing help” opens under each field the AI may write: Write, Expand, Shorten, and an optional one-line note (“mention the Dhadgaon school”). The rest of the row is the context — only the tab’s own fields, read from the registry, so nothing else in the request can reach a provider.

  • A summary too long for a home-page card: Shorten.
  • A one-line event description: Expand, from what the body already says.
  • An empty WhatsApp message for a post: Write.

The first real run: asked about a programme running “since 2019”, a Flash-Lite model wrote २०१५ in the Marathi and 2019 in the English. Now every draft is compared with its source, and a number that isn’t in the source is listed under the field: “check them before saving: 2015”. Devanagari digits become Latin digits, in code.

07WritingAI

Fill the empty fields in one call

A new programme with only a title: Fill empty fields with AI drafts the summary, body and region in both languages from what the row already says. That is the “generate programme text” feature, and it works the same on blog posts, events and values.

  • No text, no draft. A row with nothing in it is refused — “write a title first” — because a draft from nothing is invention.
  • Only what is still empty. The reply lands in fields that are empty when it arrives, so anything typed while it ran wins.
  • Undo is exact. It lists what it filled, and Undo restores exactly those fields.

09PhotosAI

A photo, described in two languages

Describe with AI in the photo library’s edit dialog drafts alt text (125 characters at most) and a caption in Marathi and English, and suggests up to three sections — Gallery, Program, Event and so on — added to whatever is already ticked.

  • Describe only what is visible. Never identify anyone, or guess age, caste, tribe or religion.
  • Never guess a place, date or event unless it is written in the picture.
  • Code drops a caption that repeats the alt text, and Marathi that slips into another Indic script — Flash-Lite once wrote शिलीमুক্ত, half of it Bengali.
  • The server loads the image by media id, under the editor’s own session; the browser never supplies a URL. JPEG, PNG or WebP, 1.5 MB at most.
10PhotosAI

Fifty photos, one at a time

Describe photos missing alt text takes up to fifty images that have none, describes them seven seconds apart — the free tier’s per-minute limit — and shows a review list with a counter and Stop.

  • A 429 waits thirty seconds and retries once. A photo it cannot read is skipped, not fatal.
  • Save ticked fills only what was empty; sections only where none are ticked.

A photo can belong to several sections

A health-camp photo can be Gallery, Program and Event at once. The library’s single “Context” dropdown became a row of checkboxes over media.contexts text[], GIN-indexed for the filter’s @>. The old context column stays until the deployed code stops writing it; a trigger bridges the gap. no AI

11GalleryAI

A gallery arranged from the library

Suggest from library with AI on the three gallery tabs proposes a category and album for each photo not yet in the gallery, and new categories and albums where the photos need them.

  • Descriptions, not images. Each photo is described once; a suggestion then costs a few hundred tokens. Undescribed photos are counted and left out, with a pointer to the bulk describe.
  • Code keeps it sane: a proposed album needs two photos and a category three, or they are dropped; a photo stays in its album’s category (the (album_id, category) key); slugs must match the CHECK.
  • Drafts, in foreign-key order. Ticking a photo ticks the album and category it needs; everything is created unpublished, categories first, then albums, then photos.
12NewsAI

Reading a newspaper clipping

In News & media, Read a news clipping with AI reads the photo chosen as the item’s image — a cutting, or a screenshot of an article — and fills the fields that are still empty.

  • Headline and outlet, as printed and translated.
  • A two-to-three sentence summary in its own words, and the coverage type.
  • The date only if one is printed, and never in the future. A photo that is not news comes back empty.

Real run, 29 September: two Marathi cuttings came back with headline, outlet (Divya Marathi, Sakal), a printed date and summaries in both languages; the third had no printed date and came back without one. One summary named “Prabodhan Foundation”. Misread or not, catching that is what the review is for.

13NewsAI

News from the library, without duplicates

Pull news from the library with AI reads photos one at a time — the News-section photos by default, or the whole library at one call a photo — and proposes a draft item for each real clipping.

  • Skips what is already there: a photo that is already some news item’s image, drafts included, is never read.
  • Drops what is not news, and says how many.
  • Flags a repeat: a headline matching an existing item letter for letter is marked “looks already added” and left unticked — the same article, scanned twice.
  • Won’t guess a date: a row without a printed one can’t be ticked until a date is typed.

15PublishingAI text

Share on WhatsApp, with the right words

In the Satpuda, a post travels by forward, not by feed. Every post now has a Share on WhatsApp button: a plain wa.me link, no script.

  • The message is the post’s new WhatsApp message field (blog_posts.share_text) — bilingual, and draftable by the AI like any other field — or else the title and excerpt. The post’s link is appended, in the reader’s language.
  • og:image comes from a post’s or programme’s cover, with its size and alt text, plus summary_large_image. That is what puts a picture in the chat preview.
16Publishingno AI

A map link for every event

The Events tab takes the address Google Maps’ Share button gives. The events page shows Open in Google Maps ↗ under the location: a 44 px link that opens a new tab.

  • A link, not an embed. An embedded map would load Google on every visit and join the privacy notice’s list of providers.
  • The database checks the host. Only https Google Maps addresses get in: maps.app.goo.gl, goo.gl/maps, google.com and google.co.in /maps, maps.google.*. Plain http, a look-alike host, a search URL or javascript: comes back as events_map_url_check.
17Publishingno AI

See where the words land, as you type

Every content tab now says where its rows appear: “Appears on: /programs/youth-dialogue-camp — its own page · /programs — the list · / — home page cards”. See it on the site opens that real page in a frame, with unsaved text pushed in as you type and the edited row outlined, in Marathi or English.

  • ?preview=1 works for signed-in writers only — the middleware asks is_writer(). A visitor who adds it gets the ordinary page: no markers, no script.
  • Preview responses are private, no-store and noindex, and skip the analytics beacon.
  • Fields are found by their saved text inside the row, so only eleven row containers carry a marker.
  • Switching the frame’s language doesn’t switch the admin’s: in preview, ?lang= renders without writing the cookie.
18ControlAI

21Under the hood

Keys, people, and a gateway that said no

Keys stay in Cloudflare

GEMINI_API_KEY, ANTHROPIC_API_KEY and AGENTROUTER_API_KEY are runtime secrets read through astro:env/server. The AgentRouter base URL is an environment variable too, not a setting: an admin-editable URL would let any admin send the key somewhere else. CI greps dist/ for AIza…, sk-… and AQ.… key shapes.

Writers only, and it fails closed

The old translate endpoint checked sign-in but not role, so a viewer could spend the key. The new one asks is_writer(), and an error there is a refusal.

Free tier, eyes open

On Gemini’s free tier, Google may use the text and photos sent to improve its products, and people may review them. The photos show beneficiaries, children among them. The owner accepted this on 29 September 2026; consent wording is flagged to the foundation, and the AI tab says it in plain words.

AgentRouter said no

It serves only the coding tools it recognises and answered 401 unauthorized client. The site calls it with an honest user-agent: YungFoundationCMS/1.0 and won’t pretend to be anything else; the tab says so, and the fallback covers it.

22What broke

What broke on the way

  • The recommended model was gone. gemini-2.5-flash answered 404 for a new key. The newer Flash models were overloaded (503), then rate-limited: 59 of 60 calls failed with 429.
  • Flash-Lite’s first drafts had Devanagari digits, a wrong year, Bengali letters in Marathi, captions identical to the alt text and a one-photo album. Each one is now a code check.
  • The Cloudflare build refused the lockfile. npm 11 wrote it and npm ci on npm 10 rejected it. Lockfiles are now written with npm 10.9.2, the build’s own npm, and dry-run before pushing.
  • “Saved” that wasn’t. A row-level-security refusal on update returns 0 rows and no error, so an editor saving AI settings saw “Saved”. The save now reads the id back and treats 0 rows as “admins only”.
  • The old rich-text field ignored AI. It read its value once on mount, so a translated body never showed, and the next blur wrote the old HTML back. Tiptap replaced it.
